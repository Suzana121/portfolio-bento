# Portfolio — Bento

Personal portfolio site for Suzana Uvadiev, built as a responsive bento grid.

Plain HTML, CSS and JavaScript — no build step.

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` — page content
- `styles.css` — layout and styling (grid collapses to 2 columns under 900px, 1 column under 600px)
- `script.js` — the interactive fraud-detection demo
